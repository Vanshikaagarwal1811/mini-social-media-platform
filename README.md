# 📱 Mini Social Media Platform
A Django-based social networking platform where users can create posts, upload images, search profiles, and interact through a simple and responsive interface.
A simple social media web application built using **Django**, **HTML**, **CSS**, and **JavaScript**. Users can log in, create posts, upload images, search profiles, and interact with the platform through a clean and responsive interface.

---

## 🚀 Features

### 👤 User Authentication

* User Login
* User Logout
* Session-based authentication

### 📝 Post Management

* Create new posts
* Add captions
* Upload images
* View all posts

### 🔍 Profile Search

* Search users by username
* View user profile details

### 🎨 Responsive UI

* Clean and user-friendly design
* Built using HTML, CSS, and JavaScript

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/Vanshikaagarwal1811/mini-social-media-platform.git
```

### 2. Navigate to project directory

```bash
cd mini-social-media-platform
```

### 3. Create virtual environment

```bash
python -m venv venv
```

### 4. Activate virtual environment

Windows:

```bash
venv\Scripts\activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Run migrations

```bash
python manage.py migrate
```

### 7. Start the server

```bash
python manage.py runserver
```

### 8. Open in browser

```text
http://127.0.0.1:8000/
```
